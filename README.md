Currency Converter

A simple web-based currency converter built with HTML, CSS, and JavaScript. The project allows users to select currencies, enter an amount, and view the converted value through an easy-to-use interface.

Features

- Convert between different currencies
- Select source and target currencies
- Enter a custom amount
- Display the converted result
- Simple and responsive user interface
- Interactive currency selection

Technologies

- HTML5
- CSS3
- JavaScript

How to Run

Clone the repository:

git clone https://github.com/rafiullah-design/currency-converter.git

Open the project folder and launch "index.html" in your browser.

No additional dependencies are required.

How It Works

The user selects the source and target currencies and enters the amount they want to convert. JavaScript processes the input and calculates the corresponding converted value.

If the project uses an external exchange-rate API, the conversion rate is retrieved from the API and used to calculate the result.
